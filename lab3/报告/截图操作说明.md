# 报告截图操作说明

> 目的：给实验报告准备可引用的终端截图。
> 建议把截图保存到 `报告/images/`，文件名按下面编号，便于插入报告。
> 演示使用独立的 `/tmp/lab3-demo.db`，不会改动仓库里的数据库。

## 0. 准备

```bash
cd /home/deng/软件工程实验/实验三/lab3-repo/lab3/code
python3 main.py --db /tmp/lab3-demo.db --reset
```

启动后会显示主菜单和演示账号。**截图 01**。

之后按下面的会话操作，每一步在“截图点”处截屏。

---

## 1. 参与者：报名成功（截图 02）

主菜单输入：

```text
1
13600000004
Pass@123
1
（直接回车，关键词）
（直接回车，最早场次）
（直接回车，最晚场次）
（直接回车，状态）
0
1
1
1
1
（直接回车，姓名默认）
（直接回车，手机号默认）
y
（按回车继续）
```

说明：

- `1` 登录参与者 4；
- `1` 浏览活动；
- 五个查询条件都留空/`0`，看全部活动；
- 活动 ID 输入 `1`（春日音乐会）；
- 选择 `1. 报名`，场次 ID `1`，票种 `1. VIP`；
- 确认支付 `y`。

在“已报名成功/已购票”提示处**截图 02**。

```text

```
