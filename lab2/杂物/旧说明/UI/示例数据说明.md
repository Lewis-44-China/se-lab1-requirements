# 界面示例数据说明

本目录及 `UI界面/` 中的 9 张 UI 图，重点是展示**页面结构、角色入口、操作状态和权限边界**，图中数据均为演示数据。

## 需要说明的内容

以下内容均为示例，不代表真实业务数据，也不要求跨图完全一致：

- 活动名称、组织者姓名；
- 活动时间、地点；
- 票价、余票、容量；
- 报名人数、出席率、退票率；
- 候补人数、排队时间；
- 审计日志条数、操作人、操作时间；
- 账号、报名编号、检票请求编号。

## 为什么跨图可能不一致

这些图是在设计过程中分批制作的，示例数据用于展示不同状态（待检票、已检票、候补中、已退票、待审核、草稿、已结束等）。不同图可能使用不同的示例活动或日期，目的是把状态覆盖完整，而不是构造一套跨图一致的数据集。

**系统规则、状态集合、权限边界以 `00_设计基线.md`、UML 图和实验一需求为准；UI 图中的数字和名称只作展示。**

## 报告中的写法

实验报告第 4 章 UI 设计部分会加一句：

> 界面图中的活动名称、时间、票价、余票、人数、候补人数、统计数值及日志条数均为演示数据，仅用于展示界面结构和状态，不代表真实业务数据；不同界面之间的示例数据不要求完全一致。
