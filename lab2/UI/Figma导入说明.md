# Figma 导入与导出说明

## 1. 打开 Figma

浏览器打开 https://www.figma.com ，登录免费账号，新建一个 Design 文件，命名“实验二 UI”。

## 2. 导入 SVG

1. 在文件里把 `01_登录注册.svg` 直接拖进画布；
2. Figma 会把它作为可编辑图层导入；
3. 选中导入的顶层 Frame，在右侧把尺寸设为 `1440 × 900`；
4. 如果字体提示缺失，选中文本，把字体统一改为 `Noto Sans CJK SC` 或 `Microsoft YaHei`；
5. 用同样的方式导入 `02_活动浏览与详情.svg`、`03_报名购票与候补.svg`。

## 3. 调整建议

- 先不要重画结构，只改：颜色、字号、间距、文案、图片填充；
- 需要交互状态时，复制 Frame 做“售罄/禁用/空状态”变体；
- 需要图片封面时，用 Figma 的图片填充替换 SVG 里的渐变色块；
- 每个 Frame 命名与导出文件名一致，例如 `01_登录注册`。

## 4. 导出 PNG

1. 选中 Frame；
2. 右侧面板底部 Export → `+` → 选择 PNG；
3. 倍率选 `2x`；
4. Export 保存为 `01_登录注册.png`；
5. 三张都导出后，放到 `lab2/UI界面/` 或先发给我检查。

## 5. 注意

- 最终 zip 只需要 PNG；SVG 源文件保留在仓库里，不放进交付包；
- 不要直接把 SVG 当最终 UI 交，Figma 调整后的 PNG 才是设计结果；
- 你在 Figma 里的修改会作为人工修改记录，后续写进 AI 使用章节。
