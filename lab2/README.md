# 实验二工作区

本目录是软件工程实验二（软件设计与建模）的工作区。

## 重要约定

- 实验一的两个交付文件 `requirements.md`、`chat.txt` 只读，不在实验二中修改。
- 实验一的两个标签 `lab1-ai-draft`、`lab1-final` 不移动、不删除、不覆盖。
- 实验二只在本目录 `lab2/` 下新增内容。
- 提交前钩子会阻止暂存 `requirements.md`、`chat.txt` 的修改；推送钩子默认阻止推送任何标签。
- 每次提交前可运行：

```bash
bash lab2/工具/检查实验一未改动.sh
```
